Safe to Upgrade? — recorded demo runs

Safe to Upgrade? reads a repo's package.json, collects the breaking changes for the target upgrade of each dependency, and deterministically searches the codebase for real usage of the removed or renamed APIs. One verdict per package: REVIEW (a breaking API is used, with file:line evidence), SAFE (breaking-change data exists and none of its APIs are used), or UNKNOWN (no breaking-change data — the tool says so instead of guessing).

Recorded demo — not a live backend. Every table and count on this page is the recorded output of a real run of verdict.py: the sample-project run stored in report.md / report.json and the real-world run stored in realworld-report.md / realworld-report.json, both logged in the project's EVALUATION.md. The data is embedded in this page exactly as those files recorded it; nothing here executes the tool in your browser.
